Dicas rápidasQuick tips

LED vermelho: sem rede. Azul: rede sem Home Assistant. Verde: tudo bem. A bomba não arranca: espera o Atraso a ligar a bomba (120 s). Relés ao contrário: assistente → Relés → sinal ALTO / BAIXO.

LED red: no network. Blue: network without Home Assistant. Green: all good. Pump does not start: wait for Pump Start Delay (120 s). Relays inverted: wizard → Relays → HIGH / LOW.
