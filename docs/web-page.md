# Device web page

`http://<device-ip>/` shows the **live diagram** (manifold, zones, pump, heat pump), the Altherma source/age/fault and tank status when those options are on, the **setup wizard**, a **schedule editor**, the **zone balance** report and live logs, with a **PT · EN** button. From 0.6.0 the wizard lists Altherma boards heard on UDP 18511 and can enable the optional [buffer tank](tank.md). Click a zone to see its sensor and change its target. No password by default ([Configuration](configuration.md)).
