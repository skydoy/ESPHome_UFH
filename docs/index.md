# ESPHome UFH

**Your underfloor heating in Home Assistant.** One relay per zone, the circulation pump and a heat demand signal, on a network cable. No cloud.

<div class="hero-install" markdown="1">
[⚡ Open the web installer](https://skydoy.github.io/ESPHome_UFH/){ .md-button .md-button--primary }
</div>

Runs on an **M5Stack Unit PoE-P4** (Ethernet + PoE): thermostats, schedules, pump and heat demand on the device, with or without Home Assistant. Drives up to 13 relays straight from the ESP (e.g. the Denkovi relay board of a DAEnetIP4) or 16 through an MCP23017. Set up from a wizard on the device web page.
